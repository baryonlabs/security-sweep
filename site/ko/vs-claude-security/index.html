security-sweep 안내

Claude Security·Codex Security와 무엇이 다른가요?

AI 리뷰는 로직 결함을, security-sweep은 알려진 취약점을 찾습니다.

Claude Security, Codex Security, Claude Code의 /security-review는 LLM이 사람 보안 연구자처럼 코드를 읽어 로직 결함(인가 우회, 잘못된 신뢰 경계 등)을 찾는 데 강합니다. security-sweep은 알려진 취약점(의존성 CVE, 서버 OS 패키지, 흘린 비밀값)을 결정적 스캐너로 빠짐없이 훑고, CVE가 실재하는지와 코드에서 실제로 쓰는지를 확인합니다. 대체가 아니라 조합입니다.

쉽게 말하면: 탐정과 공항 검색대

탐정: AI 보안 리뷰공항 검색대: 스캐너 스윕
하는 일코드를 처음부터 읽고 추리해서 설계·로직 결함을 찾습니다모든 가방(프로젝트·서버·이미지)을 통과시키며 수배 목록(CVE DB)에 오른 위험물을 빠짐없이 찾습니다
잘 찾는 것인가 우회, 잘못된 신뢰 경계, 처음 보는 수법오래된 라이브러리, 서버 OS 패키지 취약점, 흘린 비밀값, 언어별 위험 API
놓치기 쉬운 것수배 목록 대조 (의존성 CVE는 직접 안 봄)목록에 없는 새로운 수법
결과똑똑하지만 돌릴 때마다 조금씩 다름같은 입력이면 항상 같은 결과
확인 방법다른 에이전트가 한 번 더 검증수배 목록이 진짜인지 OSV로 조회하고, 실제로 꺼내 쓰는지(도달성) 확인
비용모델 토큰 (스캔마다)스캐너는 무료, LLM은 분류할 때만

자주 묻는 질문

Claude Security를 쓰면 의존성 취약점도 잡히나요?

공식 문서 기준으로 Claude Security는 의존성 CVE를 다루지 않고 기존 의존성 스캐너와 병행하라고 안내합니다. 의존성 CVE는 security-sweep 같은 스캐너 스윕이 맡습니다.

security-sweep도 LLM을 쓰나요?

스캔·검증·도달성·보고서는 스크립트로 돌고, LLM(Claude)은 P0/P1 항목을 코드 근거로 확정·조정하는 분류 단계에만 씁니다. 스크립트만 단독으로 실행할 수도 있습니다.

security-sweep이란?

security-sweep은 한 문장 요청으로 여러 프로젝트·서버·컨테이너 이미지의 알려진 취약점을 한 번에 점검하는 오픈소스 Claude Code 스킬입니다.

/plugin marketplace add baryonlabs/security-sweep
/plugin install security-sweep@baryonlabs-security
